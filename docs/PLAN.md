## 결정 기록
- 2026-10-18: 이름 SAKi Talk, 저장소 `talk`, 주소 `/talk`, 그룹별 초대(같은 그룹끼리만 보임), 메신저 몫 0.4GB(카페24 1.40GB 중 0.15GB 사용 중), 웹앱.
- 처음 설정 창은 올린 뒤 24시간 (SAKI 는 2시간). 관리자 이름·비밀번호는 지금 설정 파일에, 1단계에서 사용자 표로 옮긴다.
- 1단계: 관리자는 처음 설정의 이름·비밀번호로 메신저에도 로그인(talk_users is_admin=1, 관리 화면 비밀번호를 바꾸면 같이 바뀜). 이름이 로그인 아이디(서버 전체에서 하나). 관리자는 자기가 만든 그룹에 자동으로 들어감.
- 1단계 추가 (2026-10-18 일래 요청): 관리자는 모든 그룹에 자동으로 들어감(서버 4판). 관리 화면에서 사람마다 그룹을 체크해 여러 개 한꺼번에 정함, 바뀌면 앱이 몇 초 안에 반영(groups_rev). 로그인에 아이디 저장·자동 로그인(끄면 앱을 닫을 때 로그아웃), 비밀번호 저장은 휴대폰 비밀번호 관리자에 맡김.
- 이름 (2026-10-18 일래 요청): 가입 때 본명(name, 로그인 아이디)과 닉네임(nick, 비우면 본명). 채팅·목록에는 닉네임, 프로필에는 "닉네임(본명)". 친구·채팅방 얼굴을 누르면 프로필(다른 사람도 봄), 내 프로필에서 닉네임 바꾸기 (서버 5판).
- 알림 (2026-10-18 일래 요청, 2단계 앞당김): 웹 푸시(SAKI webpush.php 를 lib/push.php 로 옮김, 서버 6판). 로그인 뒤 한 번 "알림 받을까요?" 창(아이폰 사파리면 홈 화면 추가 안내), 설정 탭 알림 켜기·끄기(기기마다). 앱을 보고 있는 기기(15초 안에 동기화)에는 안 보냄→ 고침(서버 7판): 그 방을 보고 있는 기기에만 안 보냄, 목록 화면이면 보냄. 설정에 시험 알림, 관리 화면에 기기별 알림 켬·알림 기록, 숨기면 me/away. 방별 알림 끄기(muted)는 서버만 반영, 화면은 2단계 방 설정에서.
- 2단계 방 설정 (서버 8판): 채팅방 ☰ → 알림·위에 고정(나에게만, talk_room_members), 여럿 방 이름(모두에게, 안내 글), 같은 그룹 사람 초대, 나가기(여럿 방은 "○○님이 나갔어요", 1:1 방은 조용히 목록에서 지우고 상대가 보내면 다시 들어옴). 안내 글은 kind='system', 안 읽은 수·알림에서 뺌. sync 에 room_ids(들어가 있는 방 전부)를 같이 줘서 나간 방을 기기에서 지움.
- 프로필 사진: 휴대폰에서 가운데 정사각형 320px JPEG 로 줄여 talk_users.photo(MEDIUMBLOB, 300KB 까지)에. 주소는 api.php/photo/<무작위 24자>(로그인 없이, 오래 캐시), 바꿀 때마다 새 주소.
- 채팅방 사진 (2026-10-18 일래 요청, 서버 9판): 방 사람 누구나 넣고 바꿈(talk_rooms.photo, 640px). 하나만: 새로 올리면 예전 것은 지워짐, 바꾸기 전에 "현재 사진은 삭제됩니다" 표시(화면 안, 아이폰 파일 고르기가 막히지 않게). 누르면 크게 + "○○님이 게시한 사진입니다.", 방 안내 글 남김. 대화 목록·방 위쪽 줄에 방 사진.
- 3단계 사진·영상 (서버 10판, lib/media.php): 파일은 설정 폴더/media/<무작위 32자>.<확장자>, talk_media 표에 정보·영상 미리보기. media/start → media/chunk?key&offset(2MB, offset 이 받은 크기와 같을 때만 이어 붙임) → media/finish(메시지 kind photo/video, 본문 JSON key·w·h·dur·thumb). 내려받기 api.php/media/<열쇠>(로그인 없이, 영상은 Range). 정리: 올릴 때마다 응답 뒤 + 관리 화면 볼 때, 기간 지난 것·하루 넘게 덜 올라온 것·상한 넘으면 오래된 것부터 → 본문에 gone. 휴대폰: 사진 긴 쪽 1600 WebP(안 되면 JPEG), 영상 60초까지, 8MB 이하 mp4·mov 는 그대로, 크면 캔버스+MediaRecorder 로 480p 1Mbps 다시 만듦(영상 길이만큼 걸림).
- 5단계 (서버 12판): 길게 누르기 메뉴(반응 6가지·답장·복사/저장·삭제=이 기기에서 숨김(localStorage talk.hidden)·모두에게 삭제=내가 보낸 것만, kind 'deleted' + 파일 삭제). 답장은 talk_messages.reply_to, 내려줄 때 원래 글 미리보기(reply)와 반응(reactions [[사람, 이모지]])을 붙임(talk_decorate). 반응은 한 사람 하나, 같은 것 다시 누르면 뺌. 바뀐 메시지는 같은 번호로 'msg' 변경 기록 → 앱이 바꿔 끼움.
- 5단계 마무리 (서버 13판): 검색 messages/search(방 안 글, 최근 50개), 공지 rooms/notice(글 하나를 방 위에, 방 사람 누구나, 원래 글 지우면 내려감, 접기는 기기마다), 관리 화면 백업 내려받기(txt 읽기용·json 옮기기용, 사진·영상·비밀번호·기기 정보는 뺌).
- 동기화: talk_events 의 번호(cursor)로 바뀐 방·새 메시지만. 방 보고 있으면 2초, 목록 5초, 앱이 뒤로 가면 멈춤. 변경 기록은 30일 보관.
- 입력 중 표시 (2026-10-18 일래 요청, 서버 14판): talk_room_members.typing_at. 앱은 글자를 치는 동안 3초에 한 번 rooms/typing(on), 다 지우거나 방을 나가면 off, 입력칸에 글자가 남아 있으면 3초마다 다시 알려 계속 켜 둠(일래 요청), 보내면 서버가 끔, 소식이 8초 없으면 저절로 꺼짐. 변경 기록(talk_events)에는 안 남기고, sync 응답 typing 에 보고 있는 방의 입력 중인 사람만. 누가 입력 중이면 그 방 동기화를 1초로. 알림은 Urgency high, 관리 화면 알림 기록에 서버에서 넘기기까지 걸린 시간.
- 사키 봇 (2026-10-18, SAKI 쪽 연동 문서 saki-lite-연동.md 대로, 서버 16판, lib/saki.php): 단체방 설정에 "사키" 묶음(초대·성격 4가지·존댓말·부를 때만/가끔 끼어들기·간격 5~120분·반응 달기, 방장·관리자만). 봇은 talk_users is_bot=1(로그인 불가, 친구 목록에 안 나옴, 초대한 방에만 멤버). 글에 "사키"가 있거나 사키 말에 답장하면 응답을 먼저 돌려준 뒤 최근 30개를 SAKi Lite(`/saki/api.php/lite/reply`, 머리 X-Saki-Lite-Key)에 보내 봇 메시지로. 방마다 동시에 하나(talk_meta saki_busy, 60초), 부르는 동안 봇 입력 중, 상한 거절 말은 방마다 하루 한 번, 링크는 talk_messages.links(https 만)로 카드. 열쇠는 관리 화면 "사키" 칸 → 설정 파일 saki_lite_key (끝 4자만 보임). 열쇠를 안 넣으면 방 설정에 사키 칸이 안 보임. 응답 뒤 일이 길어져서 talk_json 에 Content-Length, fastcgi_finish_request 가 없으면 flush.
- 사키 조용할 때 대답 = 읽씹 방지 (2026-10-18 일래 요청, 2026-10-21 따로 켜는 스위치 + 시간 고르기 5분~2시간 wait, 끼어들기 간격과 따로, 마지막이 사키 말이면 안 함, 예전 끼어들기 방은 켜진 채로): "가끔 끼어들기" 방에서 마지막 사람 글이 5분 넘게 대답이 없으면 그 글에 한 번 대답(mode called). cron 이 없어 방 사람 누군가의 sync 응답 뒤에 살핌, 1시간 넘은 글은 안 함, 글마다 한 번(talk_meta saki_quiet).
